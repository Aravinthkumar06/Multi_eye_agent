# MultiView Agent

MultiView Agent is a web-based multi-browser automation dashboard.

## Phase 1
Project foundation, backend and frontend communication, and basic dashboard.

## Requirements
- Python 3.10+
- Node.js 18+

## How to run (Windows)
1. Ensure you have Python and Node installed.
2. Run a` in PowerShell to start both frontend and backend.
3. Open `http://localhost:3000` in your browser.

To stop the services, run `.\stop.ps1`.
